Android instructions

  1. Tap Download ca.crt below.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Choose the downloaded ca.crt.
  4. Tap Install anyway when warned.
  5. Return here and tap Open lab.
